## Overview

AION 2 Crafting Calculator is a web-based companion tool for AION 2 players that calculates the full raw material requirements for any crafted item, factoring in the sub-component chain to give total ore, fabric, and reagent counts. It also estimates kinah cost based on current auction house price data for efficient farming route planning.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AION 2 Crafting Calculator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Deep BOM** | Calculates full bill of materials including all sub-component chains |
| **Kinah Estimator** | Estimates total crafting cost from current auction house price data |
| **Multi-Craft Batch** | Calculate materials for crafting multiple items simultaneously |
| **Profession Filter** | Filter recipes by crafting profession and required skill tier |
